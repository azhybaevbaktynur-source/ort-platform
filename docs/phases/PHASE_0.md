# Phase 0 — Foundations

**Status**: done 2026-10-22 on branch `phase-0/foundations` (merged into `lms`).

## What changed

- **Alembic** (`backend/alembic.ini`, `backend/alembic/`): baseline `0001_baseline` of the current schema, autogenerated on empty Postgres 18 and reviewed. Naming convention on `Base.metadata` (`app/db/session.py`). `render_as_batch` for SQLite. From now on schema changes are Alembic revisions only.
- **Startup migrations** (`app/db/migrate.py`, called in `main.py` lifespan before `init_db()`): Postgres only (or `RUN_MIGRATIONS=1`). One connection, one transaction, `pg_advisory_xact_lock` (safe behind Neon's transaction-mode pooler). An existing unversioned DB (has `users`, no `alembic_version`) is stamped `0001_baseline`, then `upgrade head`. A failed migration stops startup.
- **Driver pin**: `postgres://` and `postgresql://` URLs are rewritten to `postgresql+psycopg2://` (SQLAlchemy 2.1 would default to psycopg 3, which is not installed).
- **CI** (`.github/workflows/ci.yml`): backend on SQLite; backend on Postgres 18 (`alembic upgrade head`, `alembic check`, pytest-alembic tests, full suite); frontend `tsc` + `next build`; i18n parity.
- **LMS building blocks** (`app/lms/core/`): `UUIDPKMixin`, `TimestampMixin`, `SoftDeleteMixin`; `JSONType` (JSONB on PG); `LocalizedText` + `localized()`; `LMSError` family with `{"error":{code,message,details}}` (handler registered in `main.py`, LMS errors only); cursor pagination (`paginate`, `PageOut[T]`); JSON logger with PII scrub.
- **Authorization scaffolding** (`app/core/authz.py`): actions `A.*`, `ROLE_GRANTS`, pure `decide()`, `AuthzContext` with per-request cache and pluggable `role_resolver` (Phase 1 plugs in enrollments), `can()/require()` (deleted or no role → 404, role but denied → 403).
- **Route-inventory gate** (`app/core/route_inventory.py`, `tests/test_route_inventory.py`): literal `ROUTE_POLICIES`; every existing route is `"legacy"`. Adding a route without a policy fails the test. The walker expands FastAPI 0.14x's lazy `_IncludedRouter`.
- **Upload hardening**: content check with Pillow (PNG/JPEG/GIF/WEBP only, SVG and renamed files rejected), size cap `MAX_UPLOAD_BYTES` (5 MiB, 413), stored extension from the detected format (`app/services/image_validation.py`). Bundle import already validated images.
- **No payload prints**: answer payload `print()`s removed from `mock_tests.py`; console email goes through the logger (dev only).
- **English UI**: `en.json` (201 keys), switcher with three languages, `/(en|ky|ru)` routes; `scripts/check_i18n_parity.py` (keys, empty values, placeholders).
- **Tests**: 112 → 173 on SQLite (+ 7 migration tests on Postgres). The 4 old tests that inserted rows with dangling foreign keys were fixed so the suite passes on Postgres too.

## How to verify

```bash
cd backend && /bin/rm -rf /tmp/agy_t && /bin/mkdir -p /tmp/agy_t/up && DATABASE_URL="sqlite:////tmp/agy_t/test.db" LOCAL_UPLOAD_DIR="/tmp/agy_t/up" venv/bin/python -m pytest -q -p no:cacheprovider -W ignore
# Postgres (local cluster or CI service; DB created with -E UTF8 -T template0; PGTZ=UTC):
ALEMBIC_TEST_DATABASE_URL="postgresql+psycopg2://postgres@localhost:55432/<db>" venv/bin/python -m pytest tests/test_migrations.py -q
DATABASE_URL="postgresql+psycopg2://postgres@localhost:55432/<db2>" venv/bin/alembic upgrade head && venv/bin/alembic check
python3 scripts/check_i18n_parity.py
```
Local Postgres 18: `brew install postgresql@18`; `initdb -D /tmp/agy_pg/data -U postgres --auth=trust`; `pg_ctl -D /tmp/agy_pg/data -o "-p 55432" start`.
